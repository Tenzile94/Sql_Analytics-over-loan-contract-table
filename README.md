# Loan Contract SQL Practice

This repository contains Oracle SQL queries for managing and modifying loan contract data in the `LOAN_CONTRACT` table.

## Topics Covered
- INSERT, UPDATE, and DELETE statements
- Filtering data using WHERE conditions
- Date-based filtering
- ALTER TABLE operations
- Sequence creation and usage
- Adding and updating table columns

## Tools
- Oracle SQL
- Oracle Database

## Purpose
To practice SQL data manipulation and table structure management using loan contract data.
