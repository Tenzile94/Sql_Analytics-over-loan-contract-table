7. Create a sequence with the following properties:

   START WITH    : 1000
   INCREMENT BY  : 1

   Then, add a new column named LOAN_KEY to the LOAN_CONTRACT table
   and populate it using the sequence.
*/

increment by 1

insert into LOAN_CONTRACT (loan_key) values (seq_loan.nextval)
